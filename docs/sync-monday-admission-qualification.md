# Monday SYNC admission candidate

This is a local software candidate. Full physical-latency qualification and a
different review are required before release.

three continuation legs without completing every scheduled analysis phase.
One user reached the original 30-second FAST boundary while two other users had
already entered analysis. The phase's shared yield flag then blocked their
explicit 15-second Healthspan boundaries with over 20 seconds still remaining.

The phase keeps its accumulated incomplete-work marker. Each reached reserve
remains sticky for equal or larger boundaries. A smaller original boundary may
proceed only under the same live parent authority and budget, until that smaller
reserve is itself reached. User deferred results and incomplete FAST results
still keep whole-phase completion false. No deadline, reserve, maximum leg count,
source window, physiological gate or delivery rule changes.

Owned HTTP SYNC roots can place the original SELECT 1 and the first original
admission projection in one installed-driver batch. Only three exact non-health
SQL shapes qualify: resource owner, account lifecycle, and execution owner plus
work receipt. The original runtime guard remains sequential and first. Branded
readonly checks all settle before business. Unknown projections, unmarked checks,
unowned receivers and other phases retain the separate BEGIN acknowledgement.
Writes and processing.outside are prohibited during this admission scope.

An initial rejected BEGIN retains the original bounded contention policy.
A metadata failure after acknowledged BEGIN cannot retry business or admission.
The installed driver's public closed flag distinguishes failed initial BEGIN
from acknowledged BEGIN with a failed first metadata statement. Cancellation,
expiry, caught prohibited work and uncertain COMMIT deny business or success.
Every original ownership, input/HMAC, privacy, after and pre-COMMIT check remains.

Zero RTT runs measure software behavior and physical request counts only; they
are not evidence for a 110 ms envelope or any production provider latency.

privacy-capture experiment remain in the external author evidence directory.
